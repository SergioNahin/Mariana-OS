# Mariana OS — Architecture & Product Decisions

> _"Una decisión técnica no demuestra madurez por ser compleja. La demuestra cuando podemos explicar por qué la tomamos."_

---

# 1. Propósito

Este documento registra las decisiones relevantes tomadas durante el diseño y evolución de Mariana OS.

Su objetivo es preservar el contexto detrás de las decisiones que afectan significativamente al proyecto.

Este documento permite responder:

- ¿Qué decidimos?
- ¿Por qué lo decidimos?
- ¿Qué alternativas consideramos?
- ¿Qué consecuencias aceptamos?
- ¿Cuándo se tomó?
- ¿Qué documentos afecta?
- ¿Sigue vigente?

---

# 2. Por qué existe este documento

Las decisiones importantes tienden a perder su contexto con el tiempo.

Un proyecto puede terminar conteniendo una tecnología, patrón o arquitectura sin que nadie recuerde por qué fue seleccionada.

Esto genera:

```text
Decision
   ↓
Time
   ↓
Context Lost
   ↓
Confusion
   ↓
Incorrect Changes
```
