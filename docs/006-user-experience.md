# Mariana OS — User Experience

> *"La experiencia no consiste únicamente en llegar a un lugar. También consiste en todo lo que ocurre mientras lo descubres."*

---

# 1. Propósito

Este documento define la experiencia de usuario de Mariana OS.

Su objetivo es establecer cómo debe comportarse, sentirse y evolucionar la interacción entre Mariana y el sistema.

La UX de Mariana OS debe considerar simultáneamente tres dimensiones:

1. **Usabilidad**
2. **Interacción**
3. **Narrativa emocional**

La experiencia debe permitir que el usuario comprenda el sistema sin necesidad de conocer su arquitectura interna, mientras descubre progresivamente el significado de sus aplicaciones, recuerdos e interacciones.

---

# 2. Objetivos de UX

La experiencia debe:

- ser intuitiva;
- resultar agradable desde el primer contacto;
- permitir exploración libre;
- mantener una navegación coherente;
- reducir fricción;
- preservar el contexto;
- utilizar la interacción como parte de la narrativa;
- permitir descubrimientos;
- respetar accesibilidad;
- funcionar correctamente en diferentes tamaños de pantalla.

---

# 3. Usuario Principal

El usuario principal de Mariana OS es Mariana.

Esto tiene una implicación importante:

> Mariana OS no debe diseñarse como una aplicación genérica para "usuarios".

Debe diseñarse como una experiencia personal que posteriormente pueda ser demostrada a terceros como proyecto de ingeniería.

Por lo tanto, existen dos contextos de uso:

| Contexto | Prioridad |
|---|---|
| Mariana utilizando el producto | Principal |
| Terceros explorando el proyecto | Secundario |

La experiencia emocional se diseña principalmente para Mariana.

La experiencia técnica debe poder explicarse posteriormente a desarrolladores, entrevistadores o evaluadores.

---

# 4. Personas

## Persona primaria — Mariana

### Objetivo

Explorar la experiencia y descubrir recuerdos, mensajes, fotografías y elementos relacionados con la historia compartida.

### Necesidades

- navegación sencilla;
- descubrimiento progresivo;
- contexto;
- privacidad;
- interacción agradable;
- contenido emocional.

### Fricciones que debemos evitar

- interfaces complejas;
- exceso de instrucciones;
- navegación confusa;
- demasiadas ventanas simultáneas;
- animaciones que retrasen acciones;
- elementos puramente técnicos visibles sin propósito.
